# Using the App

Every action documented in these guides — creating a launch, contributing to a raise, claiming tokens, requesting a refund — is available directly through the frontend. No technical knowledge, no code, no command line required. If you can connect a wallet, you can use Exhibition.

**For project creators** — the app walks through every launch parameter with a guided interface. Configure your funding goal, token price, vesting schedule, liquidity allocation, and all remaining parameters through a single creation flow. What you submit is what goes on-chain. What goes on-chain cannot be changed.

**For contributors** — every active and upcoming launch is visible in the app. Read the full parameter set of any launch before committing capital, contribute in a single transaction, track your vesting schedule, and claim your tokens — all from the same interface.

**For refunds** — both the standard refund and emergency refund paths are accessible through the app. If a refund is available, it is claimable directly from the interface without any admin involvement.

***

The contract functions documented throughout these guides are what the app executes under the hood. They are provided for transparency and for developers who want to interact with Exhibition directly. For everyone else, the app is the interface — the protocol is the guarantee behind it.
